Social-Media — Backend API

A powerful and modern backend for a Social Media Application built with clean architecture and scalable design.
This backend supports user authentication with OTP, posts, likes, comments, following system, media upload, and real-time chat.

🚀 Features
🔐 Authentication

User signup & login

OTP verification

Secure password hashing

JWT-based authentication

👤 User System

Follow / Unfollow users

Get followers & following lists

Update profile

📝 Posts

Create, update, and delete posts

Upload photos/videos

View posts from followed users

Like & unlike posts

Add & delete comments

💬 Real-Time Chat

One-to-one chat

Real-time messaging using WebSockets

Message history

🛠️ Tech Stack

Node.js + Express.js (Server)

MongoDB + Mongoose (Database)

JWT (Authentication)

OTP system (Email or Phone)

Multer + Cloud Storage (e.g., AWS S3) for photos/videos

Socket.io for real-time chat
